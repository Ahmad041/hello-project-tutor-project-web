Buka dokumentasi lib.h

lib.h adalah header bantuan console Windows yang diberikan untuk latihan. File ini berisi definisi fungsi, bukan hanya deklarasi. Gunakan satu file C untuk latihan awal dan include header ini satu kali; project banyak file memerlukan pemisahan deklarasi dan implementasi.

KelompokFungsiKegunaan
Posisi dan teksgotoxy, gotoPrintString, gotoPrintCharMenempatkan teks atau karakter pada koordinat
BingkaiborderLine, borderDoubleLine, borderClearMenggambar atau menghapus garis tepi
Area dan kursorclearArea, hideCursor, showCursorMengelola area tampilan dan kursor
Teks dari filePrintTxtMenampilkan isi TXT per baris
InputscanInputString, scanInputText, scanInputPassword, scanInputNumber, scanInputMoneyMenerima input sesuai jenis field
Consolefullscreen, remove_scrollbar, setConsoleFontPengaturan jendela dan font
Fungsi ini memakai Windows API. Efek font, fullscreen, dan karakter border dapat berbeda menurut terminal, font, serta code page.

Periksa library sebelum dipakai

Kerjakan sebelum compile pertama. Empat lokasi berada pada scanInputString, scanInputText, scanInputPassword, dan scanInputNumber. Di setiap cabang BACKSPACE, ganti blok if (i > 0) yang berisi text[i] = "" dengan pola lengkap di bawah; jangan menyisipkannya sebagai blok tambahan.

File unduhan tetap merupakan file asli pengguna. Catat dan perbaiki masalah berikut pada salinan latihan sebelum memakai fungsi input:

LokasiMasalahTindakan
Empat fungsi input · BACKSPACEtext[i] = "" memberikan pointer string ke charKurangi i lalu tulis text[i] = '\0'; sebagai karakter NUL
scanInputString · ESCKondisi i < 0 tidak tercapaiTetapkan perilaku batal; contoh: kosongkan buffer lalu keluar
PrintTxtfopen gagal belum diperiksa sebelum fgetsPeriksa file != NULL sebelum membaca
Semua fungsi inputBatas buffer tidak dibuktikan dari maxCharBatasi karakter dan sisakan ruang terminator
setConsoleFontwcscpy tidak membatasi panjang nama fontBatasi nama font sesuai kapasitas FaceName
Pola BACKSPACE · gunakan pada keempat fungsi input
if (ch == BACKSPACE && i > 0) {
    --i;
    text[i] = '\0';
    printf("\b \b");
}

Koreksi BACKSPACE menghilangkan kesalahan assignment tersebut, tetapi tidak menjamin seluruh fungsi sudah benar. Untuk latihan input, periksa juga batas buffer dan perilaku ESC pada tabel. Untuk file TXT, gunakan pengganti PrintTxt lengkap di modul 4. Rincian tersedia pada catatan dokumentasi library.

Lihat diagram, contoh, dan materi lengkap

Siapkan header dan compiler

Sebelum compile pertama: unduh lib.h asli, buat salinan di include/lib.h, lalu terapkan koreksi BACKSPACE pada empat fungsi input di pemeriksaan library. Semua definisi dalam header ikut dikompilasi meskipun fungsi tersebut belum dipanggil.

Simpan main.c dan lib.h pada folder include dan src sesuai struktur latihan. Pakai GCC untuk Windows, misalnya MinGW-w64. Header standar dan Windows harus di-include sebelum lib.h karena file yang diberikan belum menyertakannya.

main.c · latihan pertama
#include <stdio.h>
#include <stdlib.h>
#include <windows.h>
#include <conio.h>
#include <wchar.h>
#include <ctype.h>
#include "lib.h"

int main(void) {
    gotoPrintString(2, 2, "Halo dari lib.h");
    getch();
    return 0;
}
PowerShell · dari root kasirkita
gcc --version
New-Item -ItemType Directory -Force build
gcc -std=c17 -Wall -Wextra -Iinclude src/main.c -o build/latihan.exe -luser32
.\build\latihan.exe
Kode contoh perlu dicoba di Windows. Library asli memiliki kesalahan pada fungsi input yang dibahas pada langkah pemeriksaan; jangan menyembunyikan peringatan compiler.

Prasyarat: Windows, editor teks, dasar variabel/fungsi C, dan GCC Windows (MinGW-w64) yang dapat dipanggil dari PowerShell. Jika gcc tidak dikenali, periksa pemasangan compiler dan PATH lalu buka terminal baru. Opsi -Iinclude mencari header; -luser32 menghubungkan fungsi Windows yang digunakan library.

Hasil yang diharapkan: teks Halo dari lib.h muncul pada (2, 2), program menunggu satu tombol, lalu keluar. Jalankan executable hanya setelah compile berhasil; jika gagal, periksa pesan compiler agar tidak menjalankan executable lama.

Koordinat dan teks

Letakkan perintah berikut di dalam main, menggantikan pemanggilan gotoPrintString pada latihan pertama. Pertahankan includes, getch() dan return 0. KASIRKITA mulai di (4, 3), label di (4, 5), dan penanda di (3, 5).

Koordinat (x, y) dihitung dalam sel karakter, dimulai dari (0, 0) di pojok kiri atas. x bergerak ke kanan; y bergerak ke bawah. gotoPrintString mencetak teks setelah memindahkan kursor, sedangkan gotoPrintChar mencetak satu karakter.

Latihan posisi
gotoxy(4, 3);
printf("KASIRKITA");
gotoPrintString(4, 5, "Nama produk:");
gotoPrintChar(3, 5, '>');
Pastikan koordinat dan panjang teks muat di jendela console. Teks panjang tidak otomatis dipotong oleh library.

Bingkai, area, dan kursor

Letakkan perintah berikut di dalam main sebelum getch(), menggantikan latihan posisi. Pertahankan includes dan return 0; panggil showCursor() setelah getch() sebelum keluar. Periksa bingkai dari (2, 1) sampai (62, 16) dan judul di (5, 3).

borderLine(x, y, lebar, tinggi) dan borderDoubleLine menggambar bingkai hingga koordinat x + lebar dan y + tinggi. borderClear menghapus tepinya; clearArea mengisi area dengan spasi.

Latihan bingkai
hideCursor();
borderDoubleLine(2, 1, 60, 15);
gotoPrintString(5, 3, "Menu utama");
clearArea(5, 12, 50, 1);
hideCursor();
clearArea memanggil showCursor di akhir. Sembunyikan kursor kembali jika UI sedang menampilkan menu.

Kenali fungsi input

Gunakan salinan header yang sudah dikoreksi pada pemeriksaan library. Letakkan deklarasi dan perintah berikut di dalam main sebelum getch(), menggantikan latihan bingkai. Pertahankan includes dan return 0. Contoh ini membaca nama serta jumlah, belum menyimpan transaksi.

FungsiArgumen hasilBatas yang harus dijaga
scanInputString / Text / Passwordchar buffer[] dan maxCharmaxChar paling besar kapasitas buffer dikurangi 1 untuk NUL
scanInputNumberint *num dan maxCharBuffer internal 50 byte; jumlah digit dan nilai int harus diperiksa
scanInputMoneyint *nilai, min, maxmin/max berarti jumlah digit, bukan batas nilai rupiah
Contoh pemanggilan input
/* Coba setelah koreksi fungsi input pada langkah pemeriksaan sebelumnya. */
char nama[100] = {0};
int jumlah = 0;
scanInputString(18, 5, nama, 30);
scanInputNumber(18, 7, &jumlah, 3);
if (jumlah <= 0) gotoPrintString(4, 11, "Jumlah harus lebih dari nol.");
Masking password dengan * hanya menyamarkan tampilan. atoi tidak melaporkan overflow; validasi angka dan nilai kosong tetap menjadi tanggung jawab program.

Coba: ketik BukuX, tekan BACKSPACE sekali, lalu ENTER; buffer nama harus berisi Buku. Masukkan 2 untuk jumlah, lalu coba 0: pesan Jumlah harus lebih dari nol harus terlihat. Helper angka menghasilkan int; contoh dibatasi tiga digit (0–999). Data model memakai int untuk angka, sehingga scanner ini membaca angka bulat dengan sederhana.

Hasil modul 3: folder latihan berisi satu main.c, salinan lib.h dengan catatan koreksi, aset TXT, dan executable yang dihasilkan compile berhasil. Perlihatkan teks pada koordinat yang dipilih serta catat hasil percobaan BACKSPACE dan jumlah nol.
