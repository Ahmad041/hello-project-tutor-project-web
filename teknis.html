Periksa sebelum memakai

Periksa logika penanganan tombol BACKSPACE pada fungsi input agar pengguna bisa menghapus karakter tanpa merusak memori buffer.

BAYANGKAN BEGINI

Seperti menguji fungsi penghapus pada pensil sebelum mulai menggambar.

Coba sekarang: Periksa apakah blok else if (ch == 8) sudah memundurkan kursor dan mengurangi indeks.
Lihat diagram, contoh, dan materi lengkap
// Koreksi Bug Backspace pada lib.h (Karakter ASCII 8)
else if (ch == 8) { // Tombol BACKSPACE ditekan
    if (i > 0) {
        i--;
        printf("\b \b"); // Mundur 1 char, timpa spasi, mundur lagi
    }
}
Penting untuk Ujian Sidang: Empat fungsi input (scanInputString, scanInputInt, scanInputFloat, scanInputFormatPrice) harus menerapkan penanganan backspace yang sama agar terminal tidak mencetak karakter sampah saat pengguna salah ketik.

BEDAH ANATOMI Fig 3.7 · Anatomi Alokasi Buffer String & NUL Terminator

Alokasi Buffer Memori Karakter C char input[50] & Batas Mutlak \0

Tahap 1 / 3
1 Alokasi Array Buffer: Ukuran array char input[50] harus cukup menampung string + 1 byte terminator.
2 Penulisan Karakter: Setiap ketukan tombol keyboard mengisi indeks array secara berurutan ('B', 'u', 'k', 'u').
3 Koreksi Backspace: Tombol backspace memundurkan indeks i-- dan mencetak karakter escape '\b \b'.
4 NUL Terminator Guard (\0): Wajib mengunci akhir string dengan karakter byte 0 untuk mencegah pembacaan memori liar.
Lihat diagram, contoh, dan materi lengkap
// Latihan scanInputString dengan Batas Buffer
char namaBarang[50];
gotoxy(4, 10);
printf("Masukkan Nama: ");
scanInputString(namaBarang, 49); // Maks 49 char, byte ke-50 otomatis didedikasikan untuk '\0'
