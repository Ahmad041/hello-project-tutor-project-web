04Langkah 1 · kompilasi program pertama

Periksa compiler dengan gcc --version. Buat folder src, include, build, db, tests, dan output. Simpan contoh berikut di src/main.c.

src/main.c · fondasi menu
#include <stdio.h>
#include <string.h>

int main(void) {
    char input[32];
    for (;;) {
        puts("\nKasirKita — C17\n1. Katalog\n0. Keluar");
        if (fgets(input, sizeof input, stdin) == NULL) break;
        if (strchr(input, '\n') == NULL && !feof(stdin)) {
            int ch;
            while ((ch = getchar()) != '\n' && ch != EOF) {}
            puts("Input terlalu panjang.");
            continue;
        }
        input[strcspn(input, "\r\n")] = '\0';
        if (strcmp(input, "0") == 0) break;
        if (strcmp(input, "1") == 0) puts("Katalog belum dihubungkan.");
        else puts("Pilih 0 atau 1.");
    }
    return 0;
}
Terminal
gcc -std=c17 -Wall -Wextra -Wpedantic src/main.c -o build/kasirkita.exe

Contoh ini memverifikasi loop menu dan input; fitur katalog belum diimplementasikan. Tambahkan fitur satu per satu mengikuti langkah berikutnya. Jangan memakai gets atau fflush(stdin).

05Langkah 2 · struct dan validasi input

include/models.h

  1. Baca input dengan fgets. Tolak baris yang melebihi kapasitas, lalu buang sisanya hingga newline/EOF.
  2. Ubah angka dengan strtoll: reset errno, periksa ERANGE, pastikan minimal satu digit terbaca, dan tolak karakter sisa selain whitespace.
  3. Batasi kuantitas > 0, harga/stok ≥ 0, dan maksimum 100 produk berbeda dalam keranjang. Gabungkan ID produk yang sama.
  4. Periksa overflow sebelum perkalian dan penjumlahan. Pakai int64_t untuk rupiah, bukan float.
  5. Salin teks dengan batas kapasitas dan pastikan terminator NUL. Jangan menerima nama kosong.

06Langkah 3 · format penyimpanan TXT

Satu baris adalah satu record; pemisah field berupa |. Urutan field mengikuti kamus data. Contoh ini adalah kondisi setelah penjualan dua buku; stok sudah 18.

data/data.txt · contoh format
KASIRKITA|1
CATEGORY|1|ATK
PRODUCT|1|1|P001|Buku A5|12000|18
CUSTOMER|1|Rani|-
SALE|1|1|2026-10-01T10:00:00|30000|24000
ITEM|1|1|2|12000
END|5
  1. Buka dengan fopen(path, "r"). File belum ada pada penggunaan pertama memerlukan inisialisasi eksplisit; file gagal dibuka karena izin bukan berarti data kosong.
  2. Baca dengan fgets ke buffer 512 byte. Deteksi baris terpotong, bersihkan CR/LF, dan periksa header versi.
  3. Pisahkan token, validasi jumlah field dan tipe record. Parse angka dengan strtoll dan pemeriksaan range/karakter sisa. Tidak ada field kosong: telepon kosong memakai -.
  4. Muat ke struktur sementara yang dialokasikan di heap. Periksa kapasitas sebelum menambah elemen; jangan menaruh array transaksi besar di stack.
  5. Sesudah semua baris terbaca, cek ferror dan fclose, END|N, tidak ada data setelah END, ID unik, referensi, total detail, stok, dan pembayaran.
  6. Jika valid, aktifkan data di memori. Jika rusak, tampilkan nomor baris/alasan dan jangan menulis balik file tersebut.
Seed awal tanpa penjualan: gunakan stok 20, hapus baris SALE dan ITEM, lalu ubah penutup menjadi END|3. ID baru dihitung dari maksimum ID aktif + 1, dengan pemeriksaan overflow.

08Langkah 5 · checkout dan penyimpanan aman

  1. Validasi keranjang, pelanggan, stok, uang, dan overflow. Buat salinan state di heap, tambahkan SALE/ITEM, lalu kurangi stok pada salinan.
  2. Tulis seluruh kandidat ke data/data.tmp menggunakan fopen(..., "w"). Periksa setiap fprintf, fflush, dan fclose; hasil gagal tidak boleh dilanjutkan sebagai sukses.
  3. Baca ulang .tmp menggunakan parser yang sama dan pastikan seluruh relasi/total valid.
  4. Jika data utama sudah ada dan valid, siapkan ruang untuk backup lama, kemudian rename data.txt menjadi data.bak. Periksa tiap operasi. Jangan menghapus satu-satunya salinan valid.
  5. Rename data.tmp menjadi data.txt. Bila gagal setelah backup dibuat, coba kembalikan data.bak. Bila pemulihan gagal, hentikan perubahan dan tampilkan lokasi backup.
  6. Setelah penggantian sukses, gunakan kandidat sebagai state aktif dan tampilkan nota. Jika ekspor nota gagal, transaksi tetap tersimpan dan nota dapat diekspor ulang.
Ini pola pemulihan sederhana untuk satu proses, bukan jaminan transaksi atomik atau ketahanan mati listrik. C standard library tidak menjamin flush fisik ke disk; dua operasi rename menyisakan celah saat file utama belum ada. Jangan menjalankan dua instance bersamaan.

Pemulihan saat startup

Jika data.txt valid, gunakan file itu. Jika hilang/rusak, hentikan transaksi dan tawarkan pemulihan dari data.bak yang telah lolos validasi; jangan mengganti data otomatis. data.tmp bukan bukti bahwa transaksi berhasil, sehingga tidak diaktifkan otomatis.

09Langkah 6 · nota, laporan, dan file BAT

Simpan waktu lokal dengan format YYYY-MM-DDTHH:MM:SS menggunakan time, localtime, dan strftime; periksa hasilnya. Komputer tutorial disetel ke Asia/Jakarta. Filter laporan dengan 10 karakter tanggal setelah tanggal divalidasi. Simpan waktu transaksi lama tanpa mengubahnya.

Nota berasal dari SALE dan ITEM, bukan harga master terkini. Gunakan inttypes.h / PRId64 untuk menulis uang. Periksa fopen, fprintf, dan fclose saat ekspor.

@echo off

gcc -std=c17 -Wall -Wextra -Wpedantic -Iinclude src/main.c src/input.c src/storage.c src/checkout.c -o build/kasirkita.exe
