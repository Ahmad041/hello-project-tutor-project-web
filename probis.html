FONDASI SISTEM Materi 08

Fondasi Proses Bisnis (Probis)

Proses Bisnis adalah sekumpulan aktivitas terstruktur yang saling berhubungan untuk mengubah input menjadi output demi tujuan organisasi. Probis mencegah aplikasi salah sasaran, membantu menemukan entitas/atribut, serta menjadi dasar kondisi dan percabangan logika program C.

Komponen KasirKita (Implementasi Nyata)
Aktor Kasir melayani transaksi; pemilik mengelola data master produk dan membaca rekapitulasi penjualan.
Input Kode produk (SKU), jumlah pembelian (kuantitas), dan nominal uang tunai pembayaran.
Aktivitas Hitung total belanja, verifikasi kecukupan stok, validasi uang tunai, simpan transaksi ke file TXT, dan potong stok master.
Output Nota belanja tercetak di layar terminal atau pesan kesalahan ramah; rekap data penjualan tersimpan permanen.
● ALUR MANUAL (AS-IS)

Kasir menulis nota di kertas rangkap dan mengurangi stok secara manual. Rentan terhadap salah hitung kalkulator, selisih kas fisik, serta rekapitulasi data yang memakan waktu lama.

● SISTEM KASIRKITA (TO-BE)

Program C otomatis menghitung total, memeriksa validitas input, memvalidasi kecukupan uang, memotong stok master, dan mencetak nota. Dokumen Probis menjadi acuan pengujian dan implementasi kode.

Aturan Validasi Wajib pada Setiap Fitur

Periksa tipe data, cegah input string kosong, batasi panjang buffer, validasi rentang angka (kuantitas > 0), cegah duplikasi ID, dan pastikan referensi FK valid. Tampilkan pesan kesalahan yang manusiawi dan jangan pernah menyimpan mutasi data sebelum seluruh input tervalidasi. Validasi keyboard saja belum menggantikan pemeriksaan nilai dan aturan bisnis.

STRUKTUR DATA FISIK Normalisasi 3NF

PDM Setelah Normalisasi (3NF)

Pemisahan entitas master (CATEGORY, PRODUCT, CUSTOMER) dan entitas transaksi (SALE, ITEM) memastikan data terisolasi rapi tanpa anomali redundansi atau update.

Kuning: PK · Abu-abu: FK · Biru: UK (Unique Key) Buka diagram ukuran penuh

DFD · Aliran Data KasirKita

Pertukaran data antara entitas eksternal (Kasir / Pemilik), proses fungsional aplikasi (Kelola Master, Penjualan, Laporan), dan file store database TXT (D1, D2).

LATIHAN MANDIRI Tugas Praktik

Latihan Analisis Probis

Tuliskan satu alur transaksi penjualan lengkap dengan membedah komponen sistem:

1. Identifikasi tabel Aktor, Input, Aktivitas, Output, dan Fitur untuk satu penjualan.
2. Simulasikan contoh belanja 2 buku tulis (@Rp12.000 = Rp24.000) dengan uang tunai Rp30.000.
3. Jelaskan kondisi eksepsi: mitigasi ketika input tidak valid (misal: stok kurang) dan mitigasi jika penulisan ke file gagal.
