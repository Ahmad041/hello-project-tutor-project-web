Proses Bisnis KasirKita

Probis menghubungkan aktivitas nyata menjadi input, proses, dan output yang bernilai.

Proses Bisnis adalah sekumpulan aktivitas terstruktur yang saling berhubungan untuk mengubah input menjadi output demi tujuan organisasi. Probis mencegah aplikasi salah sasaran, membantu menemukan entitas/atribut, serta menjadi dasar kondisi dan percabangan program.

KomponenKasirKita
AktorKasir melayani; pemilik mengelola master dan rekap
InputProduk, jumlah pembelian, uang pembayaran
AktivitasHitung total, validasi, simpan transaksi dan stok
OutputNota atau pesan kesalahan; rekap penjualan

As-is dan to-be

As-is: kasir menulis nota dan mengurangi stok secara manual. To-be: program membantu menghitung, memeriksa input, menyimpan transaksi, dan menampilkan nota. Dokumen Probis menjadi acuan kebutuhan serta pengujian, bukan sekadar gambar.

Validasi wajib pada setiap fitur. Periksa tipe data, input kosong, panjang teks, rentang angka, ID ganda, dan referensi data. Tampilkan pesan kesalahan yang bisa dipahami; jangan menyimpan perubahan sebelum input valid. Validasi keyboard saja belum menggantikan pemeriksaan nilai dan aturan bisnis.

flowchart TD

    input[/"Input barang, jumlah<br/>dan pembayaran"/]
    calculate["Hitung total<br/>dari harga produk"]
    valid{"Input valid?<br/>tipe, stok, dan uang"}

    saved{"Simpan berhasil?"}

    error[/"Tampilkan kesalahan<br/>data aktif tidak berubah"/]
    start --> input

    calculate --> valid
    valid -->|"Ya"| save
    valid -->|"Tidak"| error
    save --> saved
    saved -->|"Ya"| receipt
    saved -->|"Tidak"| error
    error -->|"Perbaiki / coba lagi"| input
    receipt --> finish

Latihan Probis

Tuliskan satu proses penjualan dengan aktor, input, aktivitas, dan output.

Hasil yang perlu ada: tabel aktor, input, aktivitas, output, dan fitur untuk satu penjualan. Gunakan contoh dua buku seharga Rp12.000, dibayar Rp30.000; jelaskan juga kondisi input tidak valid dan simpan gagal.
