Dokumentasi lib.h

Referensi fungsi console Windows untuk membuat UI terminal dan ASCII art di project C.

Persyaratan

Library ini dibuat untuk console Windows. Siapkan compiler C untuk Windows yang menyediakan windows.h dan conio.h, misalnya MinGW-w64. Header asli memakai tipe dan fungsi dari header lain tanpa meng-include sendiri.

Pasang lib.h

Unduh file asli, lalu simpan main.c dan lib.h dalam satu folder. Contoh awal memakai satu translation unit karena lib.h berisi definisi fungsi dan belum memiliki include guard.

Unduh lib.h asli
main.c
#include <stdio.h>
#include <stdlib.h>
#include <windows.h>
#include <conio.h>
#include <wchar.h>
#include <ctype.h>
#include "lib.h"

int main(void) {
    gotoPrintString(4, 3, "Halo, KasirKita!");
    getch();
    return 0;
}

Compile dan jalankan

Sebelum compile pertama, koreksi empat cabang BACKSPACE pada salinan latihan menurut catatan perbaikan. Definisi fungsi input tetap ikut dikompilasi meskipun belum dipanggil.

PowerShell · contoh satu folder
gcc --version
gcc -std=c17 -Wall -Wextra main.c -o latihan.exe -luser32
.\latihan.exe

Jalankan dari folder latihan yang berisi main.c dan salinan lib.h. Jika compiler gagal, jangan jalankan executable lama. Opsi -luser32 menghubungkan fungsi Windows dalam library. Untuk struktur include/src/build, ikuti perintah pada modul 3. Contoh C di dokumentasi belum dikompilasi di lingkungan ini.

Pemasangan modul 3 · Referensi User32

Cara membaca koordinat

x adalah kolom dan y adalah baris, dimulai dari (0, 0) di pojok kiri atas. Ukuran dihitung dalam sel karakter. Setiap fungsi mengembalikan void; hasil Windows API belum diperiksa oleh library asli.

Koordinat
gotoxy(4, 3);             // kolom 4, baris 3
printf("KasirKita");      // cetak dari posisi tersebut

Hubungkan dengan modul

Modul 3: mengenal lib.h menjelaskan alatnya. Modul 4: UI ASCII art merangkai alat tersebut menjadi menu dan form.

scanInputString()

Membaca input teks dengan ENTER dan BACKSPACE.

Signature

lib.h
void scanInputString(int x, int y,char text[100],int maxChar);

Parameter

ParameterTipePenjelasan
x, yintPosisi awal kursor input.
textchar[100]Buffer hasil milik pemanggil.
maxCharintJumlah karakter maksimal, sisakan 1 byte untuk NUL.

Perilaku

Membaca getch berulang. ENTER mengakhiri string dengan NUL. Karakter selain ENTER/BACKSPACE masuk ke buffer jika i < maxChar.

Parameter

ParameterTipePenjelasan

}

Kode lengkap

main.c
#include <stdio.h>
#include <stdlib.h>
#include <windows.h>
#include <conio.h>
#include <wchar.h>
#include <ctype.h>
#include "lib.h"

int main(void) {
    int selected = 0;
    const char *items[] = {"Produk", "Penjualan", "Keluar"};
    system("cls");
    hideCursor();
    borderDoubleLine(2, 1, 56, 14);
    gotoPrintString(5, 3, "K A S I R K I T A");
    gotoPrintString(5, 5, "Panah: pilih | Enter: buka | Esc: keluar");
    for (;;) {
        for (int i = 0; i < 3; ++i) {
            gotoxy(5, 8 + i * 2);
            printf("%c %-12s", selected == i ? '>' : ' ', items[i]);
        }
        int key = getch();
        if (key == 0 || key == 224) {
            key = getch();
            if (key == UP_ARROW) selected = (selected + 2) % 3;
            else if (key == DOWN_ARROW) selected = (selected + 1) % 3;
            continue;
        }
        if (key == ESC || (key == ENTER && selected == 2)) break;
        if (key == ENTER) {
            clearArea(5, 14, 49, 1);
            gotoxy(5, 14);
            printf("Menu %s dipilih.", items[selected]);
            hideCursor();
        }
    }
    showCursor();
    gotoxy(0, 17);
    return 0;
}

Perawatan library

Catatan perbaikan

Temuan yang terlihat langsung pada implementasi lib.h asli.

Status file asli

Dokumentasi ini merujuk file pengguna yang tersedia untuk diunduh. File asli tidak diubah. Koreksi berikut adalah panduan untuk salinan latihan, bukan klaim bahwa library unduhan sudah diperbaiki.

BACKSPACE dan ESC

scanInputString, scanInputText, scanInputPassword, dan scanInputNumber berisi text[i] = "". Sisi kanan adalah pointer string, sementara sisi kiri char. Ganti cabang BACKSPACE pada keempat fungsi dengan pola berikut:

C
if (ch == BACKSPACE) {
    if (i > 0) {
        --i;
        text[i] = '\0';
        printf("\b \b");
    }
} else {
    /* Pertahankan validasi karakter dan batas input di sini. */
}

scanInputMoney memakai buffer berbeda dan tidak memiliki assignment tersebut. Pada scanInputString, i < 0 tidak pernah tercapai; jika ESC dimaksudkan membatalkan, tetapkan kontrak batal secara eksplisit, misalnya kosongkan text[0] dan keluar sebelum menerima karakter lain.

Periksa pembukaan file

PrintTxt harus memeriksa hasil fopen sebelum membaca. Contoh guard berikut ditempatkan langsung setelah fopen pada salinan fungsi:

C
FILE *file = fopen(txtFile, "r");
if (file == NULL) {
    gotoPrintString(x, y, "File teks tidak dapat dibuka.");
    return;
}
/* Baru lanjutkan fgets, lalu fclose. */

Batas buffer dan konversi angka

Batas maxChar harus lebih kecil dari kapasitas buffer agar NUL muat. scanInputNumber memakai text[50]; scanInputMoney memakai input[225]. Batas digit saja belum menjamin angka muat dalam int. Untuk konversi yang diperbaiki, gunakan strtol, periksa errno, pointer akhir, dan rentang INT_MIN/INT_MAX. Untuk ctype, gunakan int yang valid atau unsigned char; jangan meneruskan char negatif.

Header dan project banyak file

Header asli belum memiliki include guard dan berisi definisi fungsi dengan linkage eksternal. Include berulang dapat menimbulkan redefinition; include dari beberapa file C dapat menimbulkan multiple definition saat link. Include guard hanya menyelesaikan pengulangan pada satu translation unit. Untuk project banyak file, pindahkan definisi ke lib.c dan sisakan prototipe serta konstanta di lib.h.

Hasil Windows API

Library asli belum memeriksa hasil GetConsoleCursorInfo, SetConsoleCursorPosition, dan pengaturan font/buffer. Saat memperbaiki library, periksa keberhasilan API sebelum memakai struktur yang diisi olehnya. Batasi penyalinan fontName ke FaceName. Uji border pada font/code page yang dipakai.
