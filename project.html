01Kenali project C-mu

KasirKita adalah aplikasi kasir standalone yang ditulis dalam bahasa C17 dan dijalankan melalui terminal di komputer toko alat tulis. Pengguna mengelola produk, mencatat penjualan tunai, menampilkan nota, dan membaca laporan harian.

Masalah yang diselesaikan

Pencatatan manual menyulitkan pengecekan stok dan perhitungan nota.

Hasil akhir

Program executable lokal, file data TXT, nota teks, serta laporan project.

Prasyarat: variabel, percabangan, perulangan, fungsi, array, pointer, struct, dan operasi file dasar dalam C. Siapkan compiler GCC yang mendukung C17 tanpa library database tambahan. Website ini adalah media tutorial; aplikasi yang dibangun berjalan di terminal.

02Alur pembuatan project

Peta pengerjaan KasirKita dari penentuan scope hingga penyerahan. Gunakan zoom atau pilih simpul untuk menelusuri tahap dan hubungan.

Buka alur interaktif ↗

Isi berbahasa Indonesia; kontrol bawaan viewer Archify berbahasa Inggris.

Standalone untuk satu toko dan satu operator aktif. Tidak memakai server HTTP, payment gateway, atau integrasi marketplace. Versi GUI desktop dan versi web tidak dibangun dalam tutorial ini.

04Tetapkan batas pekerjaan

Termasuk

Menu terminal, master kategori/produk/pelanggan, stok awal, keranjang, checkout tunai, nota teks, laporan harian, penyimpanan TXT, testing, dan dokumentasi.

Di luar cakupan

GUI, aplikasi web, jaringan multi-user, autentikasi produksi, multi-cabang, pajak, diskon, retur, pembelian pemasok, dan pembayaran digital.

Pemilik dan kasir adalah peran dalam analisis bisnis. Program latihan belum membatasi akses menu berdasarkan akun.

Skenario yang digunakan sepanjang tutorial

Rani membeli 2 Buku A5 dengan harga Rp12.000 per buku. Total Rp24.000, dibayar Rp30.000, kembalian Rp6.000. Stok buku berubah dari 20 menjadi 18. Angka ini menjadi acuan desain dan pengujian.

06Langkah pertama & hasil modul

  1. Tulis satu paragraf masalah toko dan siapa penggunanya.
  2. Salin batas scope di atas ke dokumen kebutuhan.
  3. Siapkan tiga produk contoh dengan harga dan stok dalam bilangan bulat.
  4. Pastikan pemilik toko memahami skenario penjualan sebelum mendesain format file.
