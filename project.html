Siapkan dokumen sebelum membuat program.

Pilih tema, tetapkan scope, temukan atribut, lalu susun Probis dan Activity Plan. Fondasi arsitektur perangkat lunak yang kokoh dimulai di sini.

01 / DILEMA AWAL

Godaan langsung mengetik kode di editor.

Banyak programmer pemula langsung membuka text editor dan mengetik main(). Hasilnya: struktur kode tambal-sulam, nama atribut tidak konsisten, dan logika buntu di tengah jalan.

02 / RISIKO FATAL

Membaurkan master dan transaksi merusak sistem.

Jika nota belanja menduplikasi nama dan harga barang secara mentah, setiap perubahan harga katalog akan merusak rekap histori masa lalu. File data menjadi kacau dan stok tidak pernah cocok.

03 / SOLUSI SISTEMATIS

Sembilan langkah fondasi yang dirancang presisi.

KasirKita mengajarkan pemisahan relasi acuan, batasan scope, dan siklus SDLC nyata sebelum menulis satu baris pun kode struct C.

SIGNATURE MOVE · CETAK BIRU INTERAKTIF

Anatomi Relasi: Master vs Transaksi

Putar wheel scroll untuk mengalirkan data ▾
1 Primary Key (PK): ID paten unik K01, P001 mencegah duplikasi katalog.
2 Master-ke-Master: Kategori K01 dimasukkan ke Produk P001 untuk rak.
3 Foreign Key (FK): Nota meminjam P001 tanpa menduplikasi nama barang.
4 Mutasi Stok: Transaksi otomatis memotong saldo stok master (-2).

LANGKAH 06 / 09 · PILAR UTAMA Core Concept

Pisahkan master dan transaksi

Master adalah data acuan yang jarang berubah dan bisa masuk antar-master; transaksi adalah pencatatan kejadian yang isi datanya pasti berubah-ubah.

BAYANGKAN BEGINI

Empat kotak di meja: kotak kategori, barang, dan pelanggan adalah master yang datanya jarang berubah; kotak transaksi berisi nota belanja yang isinya pasti berubah-ubah setiap menit.

Aspek Pembeda Entitas Master (Katalog) Entitas Transaksi (Nota Belanja)
Sifat DataJarang Berubah (statis, acuan paten)Pasti Berubah-Ubah (dinamis, bertambah terus)
RelasiBisa saling terhubung (Kategori → Produk)Meminjam ID produk dari master (Foreign Key)
Aktor PengubahPemilik toko / admin katalogKasir yang melayani pembeli di mesin kasir
Operasi File CDibaca ("r"/"rb"), diperbarui saat mutasiDitambah di akhir file mode append ("a"/"ab")
// Pola Struct C: Master vs Transaksi
typedef struct {
    char id_category[21];  // K01 (Primary Key Kategori)
    char name[64];         // Alat Tulis
} CategoryMaster;

typedef struct {
    char id_product[21];   // P001 (Primary Key Produk)
    char id_category[21];  // K01 (FK: Master ke Master!)
    char name[128];        // Buku Tulis A5
    int price;             // 12000
    int stock;             // 20
} ProductMaster;
