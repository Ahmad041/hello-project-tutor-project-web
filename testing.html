Letakkan ASCII art di program C

Pada salinan include/lib.h, ganti seluruh fungsi PrintTxt lama dengan fungsi berikut. Jangan menambah definisi kedua dan jangan menempelkannya ke main.c. Lihat juga dokumentasi PrintTxt.

Pengganti lengkap PrintTxt · salinan include/lib.h
void PrintTxt(int x, int y, char txtFile[100]) {
    char text[255];
    int baris = 0;
    FILE *file = fopen(txtFile, "r");
    if (file == NULL) {
        gotoPrintString(x, y, "File ASCII art tidak dapat dibuka.");
        return;
    }
    while (fgets(text, sizeof(text), file) != NULL) {
        gotoxy(x, y + baris);
        printf("%s", text);
        ++baris;
    }
    fclose(file);
}

Simpan contoh lengkap berikut sebagai src/main.c. Header salinan juga harus sudah mendapat koreksi dari modul 3. Compile ulang dengan perintah di pemasangan library.

src/main.c · contoh lengkap
#include <stdio.h>
#include <stdlib.h>
#include <windows.h>
#include <conio.h>
#include <wchar.h>
#include <ctype.h>
#include "lib.h"

int main(void) {
    hideCursor();
    PrintTxt(4, 2, "assets/ascii/judul.txt");
    gotoxy(4, 10);
    printf("Tekan tombol untuk keluar.");
    getch();
    showCursor();
    return 0;
}
Path relatif dihitung dari direktori kerja, bukan lokasi file .c atau .exe. Jalankan .\build\latihan.exe dari root project. PrintTxt membaca buffer 255 byte; jaga setiap baris ASCII art di bawah 254 byte. Pastikan x + lebar dan y + tinggi muat dalam console.

Hasil yang diharapkan: empat baris judul contoh mulai di (4, 2), pesan keluar di (4, 10), lalu satu tombol menutup program. Untuk uji file hilang, ubah nama judul.txt sementara; setelah percobaan, pulihkan namanya. Catat pesan yang benar-benar muncul.

Jika ASCII art lebih dari 7 baris, pindahkan pesan keluar ke baris yang tidak bertumpuk. Jangan memakai trim yang menghapus spasi kiri; spasi membentuk gambar.
