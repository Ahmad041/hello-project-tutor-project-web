BEDAH ANATOMI Fig 4.3 · Anatomi Buffer String C char text[255] & Null Terminator

Alokasi Buffer Memori Stack & Mekanisme Pembacaan fgets() Baris per Baris

Tahap 1 / 3
1 Buffer Memori Stack: Array char text[255] dialokasikan di stack frame lokal fungsi PrintTxt.
2 Looping fgets(): Membaca maksimal 254 karakter atau sampai bertemu karakter newline \n.
3 Relasi gotoxy(x, y++): Baris teks dicetak berurutan ke bawah dengan menambahkan nilai variabel baris Y.
4 Pemeriksaan file == NULL: Cegah segmentation fault dengan memvalidasi handle berkas sebelum memanggil fgets.
Lihat diagram, contoh, dan materi lengkap
// Implementasi Aman PrintTxt di lib.h
void PrintTxt(int x, int y, const char *filename) {
    FILE *fp = fopen(filename, "r");
    if (fp == NULL) {
        gotoxy(x, y);
        printf("[ERROR] File %s tidak ditemukan!\n", filename);
        return;
    }
    char text[255];
    while (fgets(text, sizeof(text), fp) != NULL) {
        gotoxy(x, y++);
        printf("%s", text);
    }
    fclose(fp);
}
